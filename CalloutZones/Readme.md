# Callout Zones

<img src="https://github.com/cyanblur/CalloutZones/blob/master/CalloutZones/ThunderstoreContent/UIDemo.gif?raw=true"/>

Names zones within each map and displays them in UI when entered, or in chat when pinged.

The intent is to standardize callouts in streaming settings, multiplayer, and competitive play.
